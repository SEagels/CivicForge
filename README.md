# CivicForge / 申论锻造台

CivicForge is a local-first Windows desktop workspace for Chinese civil-service essay study. It connects practice, feedback, source collection, knowledge cards, active recall, and real answer usage into one learning loop.

CivicForge 是一款本地优先的 Windows 申论学习工作台，将训练、复盘、资料整理、知识卡片、主动回忆和真实调用连接成一个完整闭环。

## Product / 产品定位

- Five primary workspaces: Today, Practice, Library, Review, and Progress.
- SQLite is the source of truth in the Tauri desktop app.
- Single-user and local-first; no account, cloud sync, collaboration, question bank, or wrong-answer system.
- Data generated by rules or future AI providers must be verified before becoming a usable knowledge card.
- 五个一级工作区：今天、训练、素材、复习、进度。
- Tauri 桌面端以 SQLite 为唯一真实数据源。
- 单人、本地优先；不做账号、云同步、多人协作、题库和错题系统。
- 规则或未来模型生成的内容必须经过用户验证，才能成为可使用知识卡。

See [Product specification / 产品说明](docs/product.md).

## Current Features / 当前功能

- **Today / 今天**: 15, 30, or 60-minute plans, resumable study sessions, and quick capture.
- **Practice / 训练**: reading, outline, answer, and reflection stages; draft/revision comparison and manual feedback.
- **Library / 素材**: source inbox, traceable knowledge cards, quality verification, related knowledge, and legacy finished materials.
- **Review / 复习**: five active-recall modes with Again, Hard, Good, and Easy scheduling; weak cards can become micro practices.
- **Progress / 进度**: practice completion, card usage, weak reviews, topic coverage, and readable legacy Rewrite history.
- **Windows widget / 桌面小组件**: today task, daily card, and quick capture with compact, privacy, and always-on-top options.
- **Data safety / 数据安全**: transactional migrations, rollback on failure, archive v3, and v1/v2 import compatibility.

## Development / 开发启动

```powershell
cd D:\Projects\CivicForge
npm install
npm run dev
```

Desktop development / 桌面开发模式：

```powershell
npm run tauri dev
```

The Vite preview uses `localStorage` for development. The Tauri app uses SQLite.

浏览器预览仅使用 `localStorage`；Tauri 应用使用 SQLite。

## Data And Upgrade / 数据与升级

Migrations v1-v3 retain the original materials, review, and Rewrite data. Migrations v4-v8 add the 2.0 learning model and search indexes. Legacy tables remain intact, and historical Rewrite records are readable from Progress.

迁移 v1-v3 保留旧素材、复习和 Rewrite 数据；v4-v8 新增 2.0 学习模型与搜索索引。旧表不会被删除，历史 Rewrite 记录可在“进度”页查看。

- [Database / 数据库](docs/database.md)
